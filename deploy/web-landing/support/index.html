자주 묻는 질문

왜 로그인이 필요한가요?

온라인 대전의 신고·제재와 (정식 출시 후) 하루 판수·광고 제거 혜택을 계정 단위로 관리하기 위해서예요. 이메일·이름은 받지 않아요. 혼자 연습은 로그인 없이 할 수 있어요.

하루 판수 제한이 있나요?

베타 기간에는 없어요. 정식 출시 후에는 계정당 하루 1판(1판 = 최대 5라운드)이 무료이고, 모바일 앱에서 보상형 광고를 보면 늘어나요. 광고 제거를 구매하면 제한이 없어요.

업데이트는 어떻게 받나요?

PC는 첫 화면 왼쪽 아래의 업데이트 버튼을 누르면 받아서 다시 시작해요. 모바일은 스토어(지금은 APK 다운로드 페이지)로 안내해요. 웹 체험판은 새로고침하면 최신이에요.

서버에 접속이 안 돼요.

서버 상태와 소식에서 점검 중인지 확인해 주세요. 서버 없이도 "혼자 연습"으로 봇과 플레이할 수 있어요.

Windows에서 "알 수 없는 게시자" 경고가 떠요.

코드 서명 인증서가 없어서 처음 실행할 때 뜨는 경고예요. "추가 정보 → 실행"을 누르면 돼요.
